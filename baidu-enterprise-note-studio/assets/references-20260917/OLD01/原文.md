# 几个人的小团队，文件怎么放到一起？

做一个小项目，方案在群里，预算在电脑里，排期又单独发了一份。到了碰头的时候，第一件事还是：文件在哪？😵‍💫

这种情况，我会先把一个项目的文件入口理顺。

百度网盘企业版的共享文件夹，就能用来做这件事。不是把所有资料一股脑塞进去，而是先建好项目分类，再让参与的人按权限访问。

配图里这两步，比较适合直接照着找：
📎 先加人：选中要共享的文件或文件夹，添加对应成员，也可以按部门组织。
📎 再分权限：负责修改的同事设置「可编辑/同步」；只需要看资料的人，按实际分工分配权限。

比如一场活动，把方案、预算、排期放进对应项目的文件夹。下次再找东西，至少不用先问一圈“谁那儿有”。

顺便记一笔：如果想让电脑里的文件自动同步，还要在客户端配置同步任务。只把共享权限设好，这件事还没完成。

先从手上正在做的那个项目开始，通常比一次整理全公司的盘更容易落地。
