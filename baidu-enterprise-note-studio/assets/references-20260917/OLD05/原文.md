# 我：发完了！对方：还在下载……

🎬 办公交付小剧场（情景演绎）

第一幕：设计师发出链接，长舒一口气。
第二幕：对接人盯着下载进度条，沉默。
第三幕：群里弹出一句“我还没下完，等一下”。

原来“我发出去了”和“对方拿到能用了”，中间还有一段距离。

百度网盘企业版的大文件分享，有个适合做视频、设计、工程资料交付的人留意的功能：通过相应下载权益，照顾接收方的下载体验。

把交付拆成三幕，思路会更清楚：

📦 第一幕，文件备齐。
视频、设计源稿、项目附件按项目整理，再上传原文件。单文件上限等规则，以当前版本和客户端为准。

🎟️ 第二幕，核对权益。
原操作界面里有「使用下载券」等设置。分享前核对可用权益和数量，配置后，接收方可按规则使用极速下载。

👀 第三幕，检查接收体验。
有效期、访问范围、文件是否齐全，都确认一遍。支持预览的格式，可以先查看内容，再决定下载；配图保留的是原传输功能示意，并非预览操作截图。

实际速度受网络、设备和权益配置影响，极速下载也不是所有文件瞬间传完。

交付清单里，除了“链接已发”，还可以再补一项：接收方能不能顺利拿到这份文件。
