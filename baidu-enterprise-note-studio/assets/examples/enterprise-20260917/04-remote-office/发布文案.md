# 人都到高铁站了，文件还在公司电脑

人已经在路上，才想起最新方案在工位电脑里。这个时候最不想发的一句话：谁还在公司，帮我传一下。

异地办公我会先把“资料放哪”和“怎么一起改”分开处理。

百度网盘企业版的共享空间，可以让项目成员按权限从不同设备访问资料。需要把电脑上的工作文件持续同步，就在客户端配置同步任务，并确认同步完成。出发前先用手机打开关键文件，比到了现场才发现没传上去稳。

如果是几个人一起补周报、排期或汇总表，直接进入同一份受支持的Office在线文档。大家各自下载一份再修改，还是会出现好几个“最终版”。

误改时再按当前版本支持范围查看历史版本，重要文件也别只依赖一次同步。权限、同步状态、当前文件版本，这三项我会在出门前顺手看一遍。

我想要的异地协作，其实就是人在外面，资料不用跟着失联。
