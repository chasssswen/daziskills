# 新人接手项目，别让他考古聊天记录

新人问资料在哪，最怕听到一句：“之前群里发过，你往上翻。”
翻到文件还没完，还得猜这是哪一版、找谁确认。

如果要把交接做得省心一点，我会在百度网盘企业版里给项目留一个共享入口，再按「先读这里—正在做—已确认—历史资料」整理。这个分法是工作习惯，目录名可以按团队改。

共享云盘负责让资料集中存放、按权限访问；人要补上的是每个文件夹的用途、负责人，以及哪份文件是当前在用的。别把一大堆文件塞进云盘，就当交接结束了。

接手的人加入对应项目，不相关的资料不用一口气全开放。查资料和维护资料的人，也不必给同一种权限。

交接到最后，最好能回答三句话：从哪进？先看哪份？不懂问谁？这样留住的才是能接着用的资料。
