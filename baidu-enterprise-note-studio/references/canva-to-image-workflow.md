# 可画取模板，AI完成成图

1. 在用户指定集合或搜索结果里挑封面。用页面可见资源取得模板预览，记录名称、模板ID、来源页面与选用原因。只能取得预览时，如实写预览，不能声称获得可编辑源文件。
2. 本轮默认到此停止可画操作。不创建、改字、替换元素或导出设计。
3. 先看模板原图。记录标题位置、字重、素材占比、留白、色彩和阅读顺序。它是构图参考，不沿用原产品、人物、品牌和年份。
4. 每篇建立封面到内页的分镜；把已确认企业版用途放入新场景。使用imagegen，参考图顺序与作用写清楚。
5. 原UI不送去重绘。AI外围图留出精确矩形，再用原尺寸UI贴回。图片缩放只允许外围等比缩放裁切，不能改变保护图。
6. 检查每张成图与并排整批，保存可追溯提示词。

## 逐图提示词骨架

```text
任务：百度网盘企业版小红书图片，1080×1440。
参考1：可画模板，只学习[标题/摄影/图标/留白关系]，改成[工作场景]。
风格：本篇[方向]；其他篇采用[不同构图]，这篇不要混入。
标题：[准确文字]
正文：[准确短句]
构图：[上/下/斜向/网格/素材占比，具体位置]
保护区域：[x,y,w,h]，纯白留空，不生成UI或占位文字。上下文字避开。
后期素材：[原UI文件]原尺寸贴回；此字段是制作记录，不上图。
禁止：私信咨询领取、联系方式、二维码、页码、原案例等措辞、虚构按钮和速度数字。
```

## 本轮五种排法

粉白撕纸+打工猫吐槽；工作台照片+四角文件夹；蓝白科技斜向标题+部署关系；Plog照片网格+手写提醒；米色学习清单+角落办公猫。差异体现于标题层级和素材位置，不仅换色。

仓库索引没有可画模板图片本体，需要从记录的集合按模板ID重新获取。模板引用不是再分发授权。

## 留白失败的修正

生图对像素坐标的遵守不一定精确。不能只看背景漂亮就交付：先贴回原截图，再检查标题和底部句子有没有被挡住。如果挡住，重做外围：把顶部文本限制在y<250，底部放到截图结束后至少60像素；留白区域比保护矩形更大。不得通过移动必须原位的截图或压缩字形解决。保存最终修正版提示词。
