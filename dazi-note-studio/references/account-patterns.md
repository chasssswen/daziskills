## 两种入口

| 维度 | A：小杜 | B：野生代言人 |
|---|---|---|
| 常见入口 | 已经想收藏的资料、岗位痛点、旅行任务 | 搭子能生成的专属工具、设计成品、套件能力 |
| 产品出现位置 | 常在前几页资料之后，再展示提示与结果 | 更常在封面或前段出现品牌与成品 |
| 主要说服方式 | 这份东西对我有用 → 原来能按我的情况定制 | 这个工具符合我的需求 → 原来可以这样描述需求生成 |
| 场景颗粒度 | 城市、几天几晚、预算、岗位、具体文件动作 | 输入字段、功能模块、交互状态、设备和导出方式 |
| 画面语言 | 地图、照片拼贴、手绘资料、表格对照、PPT拼图 | 应用成品、手机/电脑界面、步骤编号、模块说明；也有Plog/MEME |
| 值得改进 | 标题与结果错配、长截图太小、资料知识混进能力承诺 | 多篇复用同组界面、模块太多、把原型写成全自动系统 |

它们都有教程、UGC和成品展示；差异是本批次的倾向，不是严格互斥的人设。

## 可迁移机制与页级证据

### 1. 资料先给，工具后露出

**A007 赏秋时间表**：P01–P03 为赏秋目的地与时间等可保存资料，P04 再出现输入过程，后续给预算和安排。
**A040 西安攻略**：P01–P03 用三日路线建立直接价值，后半段展示如何生成行程与费用。

作用推断：搜索特定任务的读者先获得所需信息，产品成为继续定制的方法。新稿可先交付“会议材料核对清单”，再演示如何用当前材料生成专属版本。前几页资料必须准确、有实际价值，不能拿无关知识凑页。

### 2. 把抽象能力变成一个可见差异

**A017 名单校对**：P01 两组名单与缺失项提示把“跨文件分析”缩成一个清楚问题；P02–P04 展示任务输入与对照结果。
**A020 Excel整理**：P01 的 Before/After 表格让清洗结果可视化。
**A018 扫描件**：P01 扫描前后对比，后续是输入、识别与文件输出。增强清晰度、OCR提取和排版还原要分开说。

设计决定：对照应保持同一数据对象和一致视角；截最能说明差异的几行，不堆一整张看不清的表。

### 3. 用岗位外壳承接具体任务

**A021 HR纪要**：前段办公生活画面，后段录音输入、纪要和人才信息。
**A025 RFP应答**：投标流程资料 → 知识库/材料 → 问题提取 → 答复与导出。
**A026/A029/A030 PPT**：用多页成品缩略图先展示视觉完成度，再解释选择能力、明确结构、执行与导出。

设计决定：岗位名只是入口，真正卖点是“把什么材料变成什么交付物”。投标流程图上的十二步不能因为展示了四步 RFP 草稿流程，就写成全流程替代。

### 4. 小需求翻译为工具字段

**B020 记账本**：P01 把坚持困难转成需求；P02 需求输入；P03–P04 展示记账界面和导入归类模块。
**B024 守宫台账**：喂食、补钙、温湿度、设备周期等生活细节，被转换为记录项、曲线和提醒模块。
**B032 独居管家**：P01 成品，P02 碎事列表和需求，P03 自然语言示例对应记录结果，P04 模块，P05 回到搭建过程。

设计决定：场景越小越能说清字段；优先展示一次“录入一件事—落到哪条记录”的状态变化。不要同时夸所有模块。

### 5. 从审美参考提炼变量，再替换主体

**B012 产品海报**：P01 白底商品与场景海报对照；P02 商品与参考；P03 参考分析；P04 转成商品提示；P05 确认；P06 生成；P07 多场景延展。
**B009 阴天照片**：P01 同一海边景物的前后对比；P02 原片问题；P03 指令；P04 结果及提示。
**B044 Plog**：P01 生活氛围拼贴；P02–P03 输入与生成；P04 我拍的/AI绘制的对照。

设计决定：把风格拆成主体、光线、镜头、布局、配色、材质，再将真实商品特征和已确认卖点带入。水润→水与清透光是视觉联想，不能凭此新增保湿功效、规格或认证。

### 6. 梗推动一个真实制作任务

**B015 拼豆**：P01 黄底梗角色→像素图；中段分步骤；末页成品陈列式画面。
**B026 雪影**：角色/图纸封面 → 上传参考与指令 → 生成图纸 → 色号材料 → 完整网格图。
**B034 图纸生成器**：P01 角色与图纸吸引兴趣，P02 角色原图和版式参考，P03 工具参数界面，P04 一组输出，P05 方法回顾。

设计决定：可保存的结果是网格、尺寸、色数、用量，不只是一个可爱角色图。生成图不能冒充已经拼出的实物；实物照片要有实际来源。

### 7. 把信息整合变成一个使用时刻

**B027 通勤穿搭**：P01 全天卡片；P02 定时需求；后续天气分析、指标和穿搭结果。
**B029 川西穿搭**：P01 杂志式人物与单品；P02 目的地和偏好；P03 天气与方案；P04 生成与修改。
**B049 周报**：P03–P04 可见自动化入口及任务设置，P05 产物入口；支持讲设置流程，不能据此证明永久稳定运行或精确节省时长。

设计决定：让结果在“早上出门前”“周五汇报前”发生价值。实时天气、期限和自动化依赖需要本次核实。

## 从两账号组合一条新生产链

1. 用 A 的方法找到读者想保存、想交差、想摆在桌上的具体对象。
2. 对照核心功能总结，选出主推功能，再用 B 的方法把需求拆成输入、动作、约束、字段和输出格式。
3. 先做或取得能证明结果的材料，再决定标题能够说多大；没有实测就明确使用示例。
4. 封面围绕成品或阻力，正文与内页都点出搭子功能，并用同一任务的动作和结果讲清使用价值。
5. 复用推导方法，替换具体问题、材料、构图与叙事，不沿用原作者个人故事。
