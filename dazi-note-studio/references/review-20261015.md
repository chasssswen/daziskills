# 百度搭子真实界面与官号投放约束 · 2026-10-15

在百度搭子项目制作、改写或返修笔记时，以下规则优先于下方及引用资料中有关AI场景合成、虚构演示和素人UGC的旧规则；其他项目不自动套用。

**同日再次纠正：洗稿沿着每篇原稿的风格走，在里面更换内容。** 先保留原稿有效的字体气质、配色、画面密度、叙事顺序和传播表达，再选择标题、主体、案例、背景、布局等变量实质改写。官号身份只纠正叙述视角和产品归属，不能把不同原稿统一重设计成说明书、品牌手册或一套截图模板。无AI合成场景的约束用真实照片、真实界面和保真拼贴落实，不能因此抽掉原稿的视觉风格。先将重做封面及真实UI内页与对应原稿并排自检，方向成立后再扩展整篇。

1. **封面与发布标题不能同时出现“百度搭子”。** 封面已出现品牌名（含截图内可见字样）时，发布标题不再出现；标题使用品牌名时，封面不出现。品牌归属在正文和适用内页讲清，不为避重而隐藏产品关系。所有交付文字与图片均不得出现 `Dumate`，大小写、空格变体、Logo、UI角落、输入框、成果内文与话题一并检查；选用中文界面或裁取合适局部，不涂改控件伪造中文版。
2. **使用真实操作搭子的界面，不用AI合成的场景或伪造UI。** 可以裁切、等比放大、标注和拼接真实截图，也可让AI辅助真实截图拼版；不能让AI重绘、补造或篡改界面内的按钮、输入提示词、对话、任务状态与结果。已有同任务真实素材可复用；更换案例或输入后素材不匹配，就补采对应真实界面，不能改截图文字冒充操作。搭子实际生成的成果可以展示，但须有对应操作与真实输出来源，不能用另行生图的效果冒充搭子成品。
3. **官号投放采用百度搭子官方身份的产品演示、使用指引表达。** 文案、图内标题、对话外说明和整组叙事都须适合百度搭子官号发布，不以KOS或素人视角分享；讲清适用场景、具体操作与成果价值，语言清楚自然，不扮普通用户偶然发现、亲测推荐或虚构使用经历。示例提示词中的第一人称需求不等于账号自述，可保留。使用用户提供或项目中已核实的现行中文官方Logo，原样等比放置，不由AI重绘。此条针对for官号投放用途，不把所有其他用途统一改成官号文风。
4. **每篇笔记都要包含真实界面的使用指引。** 至少能看清“在搭子输入什么提示词/材料 → 如何操作 → 得到什么成品”，配有真实输入/对话截图和对应成品展示；可跨页或用真实截图拼图，不要求每张图都有教程。仅有文字步骤、Logo、空白首页、下载卡或孤立成果不能通过。正文同步提供可复制提示词，输入、步骤与成果必须属于同一任务。
5. **操作引导词必须核对搭子真实界面。** 每个入口、按钮、菜单、页面名和操作动词都有适用真实截图或当前实操依据；不沿用其他软件或旧版界面的引导词，不把用户生成的工作台名称说成搭子原生入口。区分用户输入的提示词与产品按钮文案；拿不准的入口先核实，无依据不编写点击路径。

**真实界面的获取方式（同日补充）：** 可以直接复用待改写原稿中的真实搭子操作界面局部，以及同任务的对应成品，不要求每篇重新运行。原稿素材缺失、不清晰、过时或与新案例不匹配时，可以在浏览器中实际操作搭子，截取对应的输入、处理与成果画面，再据此改写和拼版；在用户任务授权范围内补采，无需仅为截图来源再重复确认。需要登录时复用用户已有会话，遇到必须本人完成的登录或验证再请用户处理。复用原稿只保护真实界面及对应成果，外围文案、构图与排版仍按官号要求改写，不整页照搬，也不把复用素材记成本轮新实测。

交付前逐篇核验：封面与标题的品牌组合、全部图文英文品牌残留、真实截图来源及拼版保真、官号文风（适用时）、输入到成品的使用指引、操作词与真实界面的对应关系。原尺寸目检与OCR辅助检查覆盖最终图片和笔记正文，再核对预览、ZIP中的实际版本；任一项失败就修实际成品。纯skill更新不触发历史成品返修或重新出图。
