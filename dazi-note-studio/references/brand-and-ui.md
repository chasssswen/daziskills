## 如何设计真实操作展示页

- 封面：场景标题 + 清晰可识别的官方 Logo/IP。保留 MEME、UGC、大字知识卡等所选视觉；品牌资产不迫使所有笔记变成相同模板。
- 操作页：以可读的截图或相关局部为主体，外围短句解释“在做什么、为什么需要这一步”。
- 对多步骤攻略，可依次展示任务输入、确认/执行、交付文件和结果局部，页数由材料决定。
- 只放通用首页、品牌海报、绘制的聊天框、箭头流程或自制结果，不能替代功能操作页。
- 不必每页都有 UI，但整篇应看得出真实产品使用过程；本用户要求“加一些真实操作展示页面”时优先给连续步骤，而非角落放一张很小的截图。

## 原样合成与标识

Logo、官方 IP 和 UI 使用原文件本地合成；AI 负责外围视觉，不重新画精确品牌或产品界面。可等比缩放、裁去无关外框，但不能改按钮、文件名、输入、页数、结果或状态。用户要求某区域原像素不动时，按其范围保留原尺寸并检查像素。

正常字体在最终画布排版，优先改换行与文字长度，不压缩带字图块。UI 是裁切图时保留足以理解操作的上下文；不因裁切让一个“待确认”画面看起来像“完成”。

合成后查看每一页，确认截图未遮挡、关键字可读，放入的内容与源裁切或其等比版本一致。来源不清或 UI 自身可疑时换素材，不冒充已验证实操。

发布侧可轻量标注：
- “参考界面 · 篇幅确认”
- “参考案例预览”
- “图中页数属于该例，按自己的要求选择”

当前实操才写“本次操作”；参考界面写参考来源。保留一次必要说明即可，不把内部资产台账塞进正文。
