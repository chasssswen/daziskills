# 百度搭子 DuMate 核心功能总结

版本：2026-09-11  
用途：百度搭子产品能力学习、内容策划和小红书投放素材创作参考

## 一句话定义

百度搭子 DuMate 的核心不是“陪你聊天”，而是：

> 用自然语言派活，让智能体理解任务、调用工具、操作文件和应用，最后交付可使用的结果。

产品定位：通用智能体  
产品 Slogan：真干活，用搭子  
官网：www.dumate.cn

## 四条主能力线

### 1. 文件和信息处理

从多个文件中查找信息、理解内容和关系，再整理成结构化结果。

典型任务：

- 跨 Word、Excel、PPT、PDF 提取关键信息；
- 比对多个版本的文件和名单；
- 从合同、纪要、报告中提取条款和结论；
- 批量整理、分类、归档和转换文件格式。

### 2. 数据和报告生产

从原始数据或资料出发，完成清洗、关联、分析、可视化和汇报材料制作。

典型任务：

- 清理空值、重复项和不统一的数据格式；
- 跨表关联、透视汇总和多维分析；
- 生成图表、数据看板和分析结论；
- 根据月度或季度数据生成汇报 PPT。

### 3. 浏览器和办公自动化

代替人工完成查询、填表、下载、整理、截图等重复操作。

典型任务：

- 浏览网页并查询信息；
- 自动填写网页表单；
- 下载和整理资料；
- 操作周报、报销、审批等业务系统；
- 读取、分类、总结和辅助处理邮件。

### 4. 内容和设计生产

从一个想法、主题或一组资料出发，生成可继续修改和交付的内容成果。

典型任务：

- 生成 PPT 结构、配文、配图和排版；
- 完成调研报告、竞品分析和行业资料整理；
- 设计官网、App、后台和网页方案；
- 生成直播摘要、短视频文案和社媒物料；
- 生成小红书图文、自媒体选题、封面和发布方案。

## DuMate 的核心工作方式

DuMate 的差异化价值是“执行闭环”，而不是单纯输出一段文字：

```text
理解需求
→ 拆解任务
→ 调用技能和应用
→ 处理文件与信息
→ 执行具体操作
→ 生成可交付成果
→ 根据反馈继续修改
```

用户交代任务时，最好同时说明：

1. 想完成什么目标；
2. 使用哪些资料或文件；
3. 有哪些限制和判断标准；
4. 希望输出什么格式；
5. 哪些步骤需要本人确认。

一个完整的派活示例：

> 请读取这 3 份销售数据表，统一字段并去掉重复记录，按地区和产品线进行汇总，找出变化明显的项目，生成一份可编辑的汇报 PPT；不确定的数据单独列出，结论保留原始数据依据。

## 官方资料中的主推场景

项目资料中重点出现的 DuMate 能力场景包括：

- 多端协同：手机发起，电脑本地执行，结果回传手机；
- PPT 制作：主题和资料 → 结构 → 配文配图与排版 → 可编辑 PPT；
- 深度调研：复杂课题 → 多轮检索和交叉验证 → 推理提炼 → 结构化报告；
- 设计套件：一句需求 → 官网、App、后台等设计方案 → 高品质成果；
- 直播内容总结：直播链接 → 滚动摘要 → 高光和金句 → 多平台物料；
- 自媒体套件：热点 → 选题 → 文案、封面和素材 → 发布复盘；
- 金融套件：信息整理、分析、提醒和复盘；
- 行业任务：售前/RFP、跨境内容、多渠道营销、采购合同、招聘和教学内容。

## 对外表达重点

投放内容不应只罗列“支持什么功能”，更应该说明：

> 你只需要把任务交代清楚，搭子会把散落的资料、文件和操作步骤，整理成一个真正能交付的结果。

推荐的内容表达顺序：

```text
具体场景
→ 人工处理的卡点
→ 一句话派活
→ 搭子执行过程
→ 可核对的成果
→ 人工复核边界
```

适合小红书素材的具体表达方式：

- 用一个真实身份和具体时刻切入，不从产品功能总表开始；
- 展示“什么材料变成什么结果”，避免只说“效率提升”；
- 有真实 UI 或成果图时优先展示真实证据；
- 没有真实证据时，使用明确标注的概念示意，不伪造产品界面、数据和用户反馈；
- 一条内容只重点证明一个人群、一个痛点和一条任务链路。

## 能力边界与合规要求

以下内容不能仅凭参考笔记或宣传文案直接当作产品保证：

- 生成网页不自动等于接入实时数据、后台定时任务或多人共享数据库；
- 参考笔记中出现的功能、结果和效率数字，需要以当前版本实际验证为准；
- 没有证据时，不写“节省几小时”“百分百完成”“自动替代全部人工”等确定性结果；
- 不伪造 DuMate 产品 UI、二维码、数据、用户评价或不存在的案例；
- 金融方向只能表达信息整理、分析、提醒和复盘，不得荐股、承诺收益或替代投资决策；
- 涉及删除文件、系统修改、数据外发等高风险操作时，应保留人工确认环节；
- 涉及价格、免费、积分、套餐等时效信息时，必须重新核验，不能永久写死。

能力来源标记：

- **已确认**：用户明确提供、当前官方说明已写明，或已完成真实操作验证；
- **样本展示**：参考笔记或案例中出现过，只能作为内容表现方式学习；
- **待验证**：由界面或文案推断，不能写成产品保证。

## 与图文投放生产系统的关系

本项目的图文生产系统应围绕“任务—输入—执行—交付”组织内容：

1. 先确定核心人群和具体任务；
2. 再明确需要上传或引用的输入资料；
3. 将 DuMate 能力翻译成读者看得懂的执行动作；
4. 为每页图文安排一个可检查的结果或证据；
5. 最后补充使用边界和轻量 CTA。

生成图文时，优先表现以下关系：

```text
散落文件 / 原始数据 / 一句话需求
→ DuMate 拆解与执行
→ 表格 / 报告 / PPT / 网页 / 内容包
```
