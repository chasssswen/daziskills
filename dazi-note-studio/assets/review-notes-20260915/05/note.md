不会PS也能做！一张产品图直接变上新海报​
Zoey
9月10日修改
​
最近给店里的香薰做上新，发现最费时间的根本不是拍产品图……​
是拍完以后还要：​
找参考、抠图、想配色、排标题、改版式😭​
以前一张白底产品图，从“能看”折腾到“能发”，半天就没了。​
这次我直接拿百度搭子试了一下。​
没有提前做设计稿，就准备了两样东西：​
一张香薰产品白底图＋一张我喜欢的参考海报。​
然后直接让它按我的要求重新做👇​
① 打开百度搭子 PC 端，进入【新任务】​
② 点输入框旁边的【+】​
把产品图和参考海报一起加进去​
③ 把需求一次说清楚​
我这次大概是这样说的：​
“用我上传的产品图作为主体，参考另一张海报的构图和氛围，生成一张3:4竖版新品海报。整体用奶油米白＋低饱和绿色，保留产品外观和比例；文字只放‘秋日上新 / 木质调香气 / 一句卖点’，不要堆字，留白多一点。请先给我2个差异明显的方案。”​
这里真的建议不要只说一句：​
“帮我做张好看的海报。”​
把尺寸、配色、产品重点、文字多少都讲清楚，第一版会省很多修改时间。​
④ 第一轮先让它给2个方向​
不用一开始就死磕细节。​
先看哪个构图更接近自己想要的，再直接继续追加：​
“产品再放大15%”​
“背景装饰少一点”​
“标题只留两层”​
“整体再高级、克制一点”​
比我自己重新开PS拖图层快多了……​
而且我发现这种方式特别适合：​
小店上新图 / 电商活动图 / 产品宣传图 / 小红书配图。​
手里只有一张普通产品图，也可以先丢进去试试。​
不会设计不代表只能套模板，​
现在更重要的可能是——​
把自己想要什么，跟AI说清楚。​
