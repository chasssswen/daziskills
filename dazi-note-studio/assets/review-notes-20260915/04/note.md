以前每天上班第一件事就是——​
开网页、搜热点、挑重点、整理内容、再发给同事……​
单看每一步都不难，​
但架不住每天都要重复一遍啊😭​
尤其早上事情一多，光整理行业资讯就能磨掉不少时间。​
最近开始用百度搭子的「定时任务」，​
我终于把这件事从每日待办里划掉了。​
设置其实比我想象中简单👇​
直接在百度搭子新建任务，告诉它：​
“帮我每天早上8点总结AI热门资讯。”​
不用自己搭什么复杂流程，​
它会直接识别你要做的事情和执行时间，​
然后自动创建成一个定时任务。​
创建好以后还能看到👇​
✅ 任务名称​
✅ 每天几点执行​
✅ 具体执行内容​
✅ 当前是否启用​
✅ 下一次执行时间​
之后想临时跑一次也可以，​
在左侧点进「定时任务」，就能直接管理。​
还能看到之前什么时候执行过、有没有完成，​
不用每天重新输入同一遍要求。​
我现在比较喜欢把这种功能用在：​
📌 每日行业资讯​
📌 竞品动态整理​
📌 固定日报/早报​
📌 重复性的资料搜集​
这种每天都得做、但流程又特别固定的事情，真的很适合直接丢给AI。​

我到公司 → 开始搜资料 → 整理早报​
