# 面包都出炉了，海报还没出炉

面包已经摆进柜台，我还在给上新图挪标题。越挪越像菜单截图。

这次把产品照片和一张喜欢的海报一起传给百度搭子：参考图只借大字和商品放大的排法，颜色换成深棕，主角还是我这只巧克力可颂。

我没有让它自己编一堆卖点，就写产品名和“酥皮层层·巧克力香”，比例直接要3:4。最想保住的是右边那层巧克力，别为了做图给我变成另一款面包。

后面又补了一句：可颂再大点，装饰少点，字别压上去。比起满屏“新品必买”，我更想让人先看清楚面包。

原图和成品放一起了，最后一张是完整海报。给搭子的那段话也留在图里，换成自己的产品和文案就能继续改。
