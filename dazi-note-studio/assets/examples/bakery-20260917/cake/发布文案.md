# 我家蛋糕，终于有了像样的上新图

不是蛋糕不好看，是我之前的上新图太像工作台存档了。白白拍了半天。

我想要那种甜品店橱窗里的粉白海报，但又不想套模板之后，蛋糕被装饰挤成小小一个。就把产品照和参考图发给百度搭子，让它借一下参考图的主次关系，换成粉白、留白多一点的版本。

提示词里我专门写了：草莓数量、奶油花和蛋糕形状都照原图保留。别做着做着，比柜台里的实物还多两颗草莓。

颜色我想要淡一点的，所以又补了这句。最后只留“草莓奶油蛋糕”和一行小文案，3:4竖版，看着清爽很多。

这类产品宣传图我现在会先让搭子做一版，再继续说哪里要改。产品没换，换的是让人一眼看懂它的排法。

## 发给搭子的提示词

用图1的草莓奶油蛋糕做3:4上新海报。图2只借主次层级，改成粉白甜品橱窗风，多留白。草莓数量、奶油花和蛋糕形状按原图保留。写“草莓奶油蛋糕”“给普通的一天，加一点甜”，不加价格和促销字。输出PNG。

## 追加修改

粉色再淡一点，蛋糕别换样子，也别挡住草莓。
