# 这俩贝果，终于不用在工作台出道了

这两只贝果躺在工作台上，怎么看都像备货记录。问题倒也不是面包，是背景太诚实了。

这回想做张蓝白配色的早餐小报。我把产品图和参考海报传给百度搭子，没让它照搬参考的颜色，只借大标题和商品之间的关系。

要求很简单：还是原来的两只，叠放别变；不要给原味贝果加芝麻，更别突然塞个夹心。标题就写“早餐换个圈”，产品名写清楚，3:4。

我最喜欢这版留了不少空白，贝果够大，没有十几个卖点围着它转。原图、搭子里的指令和完整成品都放上来了。

做这种上新图，先把“哪些能改、哪些不能改”说清楚，比只说一句“帮我弄高级点”省心。
