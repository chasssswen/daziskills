# 烘焙店面包上新，海报别再花钱找人做了！

开店、做电商、做自媒体的朋友，是不是经常为海报发愁？ 找设计师贵，自己做又不会PS。最近用百度搭子试了一下：上传两张图、说句话、选个尺寸，AI直接给我出了一张电商海报📱

🔹 第1步：打开百度搭子，上传两张图
📷 你的产品图 把你自己的产品照片传上去，手机拍的就行，AI会自动识别主体
📷 你喜欢的参考图 找到你喜欢的风格参考图，构图、色调、版式都可以，AI会帮你分析拆解风格
丢出两张图，AI就能理解你要什么产品和什么风格。

🔹 第2步：输入指令和需求
把核心产品和卖点告诉搭子
AI会自动拆解需求，确认产品主体、核心卖点、风格参考、海报类型。

🔹 第3步：确认尺寸和比例
AI会弹出确认选项：
📐 海报尺寸
1:1 方形（小红书/电商主图）
3:4 竖版（手机海报）
16:9 横版（公众号头图）
9:16 手机壁纸/短视频封面
选完直接生成，尺寸不合适可以重新调整。

如果你也需要做电商海报或者产品宣传图，可以试试把需求丢给百度搭子。
